Networking Overview: IPv6 & SRv6

What is IPv6?

Internet Protocol version 6 (IPv6) is the next-generation network layer protocol created by the Internet Engineering Task Force (IETF) to replace IPv4. While IPv4 uses 32-bit addresses—limiting the global pool to roughly 4.3 billion addresses—IPv6 utilizes a massive 128-bit address space, providing around 3.4 × 1038 distinct addresses.

In addition to solving IP exhaustion, IPv6 streamlines packet processing through a fixed 40-byte header, eliminates the architectural bottlenecks of Network Address Translation (NAT), and provides native support for stateless address autoconfiguration (SLAAC) and multicast communications.

What is SRv6 (Segment Routing over IPv6)?

SRv6 (Segment Routing over IPv6) is a source-routing architecture implemented natively on the IPv6 data plane. Instead of requiring transit routers to maintain end-to-end path states or rely on complex signaling protocols (like MPLS, RSVP-TE, or LDP), the ingress node encodes the network path instructions directly into the packet header.

This is accomplished using an IPv6 extension header called the Segment Routing Header (SRH), which contains an ordered list of 128-bit Segment Identifiers (SIDs). Each SID behaves as an explicit instruction: it can direct the packet to a specific node, enforce a strict traffic-engineered path, or execute a specialized network function (such as firewall filtering or VPN endpoint decapsulation). SRv6 simplifies network architectures by unifying routing and service delivery entirely within native IPv6.
